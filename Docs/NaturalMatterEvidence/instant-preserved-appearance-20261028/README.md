# Approach preparation, preserved prop meshes and continuous ground

October 27, 2026 (Denver), October 28 UTC evidence. This is a source checkpoint,
not a new downloadable release or full-scene performance acceptance.

Approached hard matter begins preparing at 12 m on the aim ray, in the existing
single editable session. Checks run every 0.35 s, retain the aimed target for 2 s,
and skip speculative work under the terrain memory guard plus a 512 MiB reserve.
Looking away restores an unedited target; an abandoned background preparation must
drain before another starts. Preparation never authorizes a cut. Actual punching
still requires current focused input within 2.5 m and uses the 0.25 m sphere.
Remote population cells are rejected before exact ray queries. Adapted roots now
copy the immutable upper template directly, avoiding a second full-world copy.

Activation borrows the actual published prototype/root mesh parts, material and
shadow policy, instead of replacing the specimen with coarse cubes. Intact matter
needs no mesh worker or upload. Cuts snapshot compact ownership on the main thread;
a background worker builds a byte-per-chunk ownership mask and exact local greedy
patches, preserving intrinsic colors, ambient occlusion and exposed interfaces.
Mask and patches publish together at a matching revision. Original meshes remain
borrowed; shared assets survive disposal. Uniform falling chunks reuse the same
original geometry, transformed by native rigid-body pose. Geometry caps report a
failure and restore the original rather than silently reducing fidelity.

Connected terrain is now the default on the next Play, including nearby contact
surfaces. Shared grid vertices use continuous sample heights and interpolated
colors; the contact grid is 0.4 m. Existing whole-pass distant refinement, source
refresh, retirement and memory limits remain. HeightProxySurface cache version is
2. This changes a replaceable render cache, not generator provenance or 10 cm
matter. Versioned saved options preserve the new default for old preferences;
no saved preferences, scene, package or source data were rewritten.

## Open acceptance and limits

Full forest walking, maximum-tree first-punch latency, whole detachment/falling
appearance and combined native frame times remain unmeasured. Cold teleports,
memory pressure or a just-selected target can still await the single preparation
slot. This is aimed approach prewarming, not every forest tree permanently active.
One modified prop session, temporary inventory and restoration limits remain.

Connected terrain uses skirts, not matching stitched LOD edges. Native close/far
seams, snow/water/shadows, walking and prop intersections need acceptance. Player
collision retains source-backed 10 cm voxel tops; continuous visual heights can
differ, especially on slopes. Coarse source data can still look faceted/patchy;
mesh refinement does not produce full-view 5 m learned data. Prior memory-blocked
missing distant ground and free-fall/stump follow-up gates remain open.
