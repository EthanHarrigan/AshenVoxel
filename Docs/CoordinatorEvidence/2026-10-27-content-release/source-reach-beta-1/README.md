# Source/reach beta integration

Frozen candidate, not native accepted. Existing local matching service and authoring
live-refinement flag are used. No model/service/dependency launch or whole-world bake.
Current and forward regions share two bounded requests; source failures/timeouts
keep original coarse coverage. Startup waits at most20s for verified5m current
source before any player/population/matter; actual resolution, not pending count,
decides success. A newly detailed height above the saved camera lifts only the
runtime spawn; the saved coordinate is preserved. Source replacement is permitted
in sufficiently high flight only after old/new conservative512m clearance and no
gameplay-matter owner. Ground-level publication remains protected; a completed
destination can wait for a safe gate. Boost defers transient current demand.

Publication invalidates the terrain queue and affected population, including near
cells after verified airborne publication. Matter ownership holds all publications.
Immutable source state content hashes include actual height/climate bytes, geometry,
blend and patch composition rather than session revision alone. Persistent render
cache adoption is separate; this identity prevents stale cross-session cache hits.

Includes the frozen six-file terrain-reach-controls-1; preserve its65 focused/API
evidence as settings/planner evidence. Normal rollback/default neutral reach, reach
1..4, plan limit16384 and far quota8192MiB are requests/limits, not allocations or
guaranteed achieved quality. Existing system commit guard remains unchanged.

Combined5 runtime API assemblies pass;37 source-focused checks pass. One actual
saved-valley source request returned valid original pretrained5m data in8.60s,
three of four owner blocks absent beforehand. This proves actual availability,
not Unity source publication, runtime source/render parity, FPS or final fidelity.
Native gates: import/compile, pre-spawn resolution/source height, dynamic source
revision/population invalidation, same valley view and known coarse/fine seams.
